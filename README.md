# One Line of Wonder

make.fun bounty `u-pangg7-one-line-of-wonder-ee10fcd8` (program/v1).

One line of wonder: a small concrete fact about starlight that keeps unfolding after it is read.

## Entry

```
The light from the star you're looking at tonight left it before your grandmother was born — and it still found your eye.
```

## Program

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). It is deterministic: the same bytes on every run.
